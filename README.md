# Scale Factory ERP — «Рабочее место»

Здесь лежат только готовые установщики программы «Рабочее место» для
Windows и macOS. Исходный код живёт в закрытом репозитории — этот
репозиторий существует затем, чтобы сотрудник мог скачать программу без
входа в GitHub.

## Скачать

Всегда свежая версия:

| Система | Файл |
|---|---|
| Windows | [ScaleFactory-Setup.exe](../../releases/latest/download/ScaleFactory-Setup.exe) |
| macOS | [ScaleFactory.dmg](../../releases/latest/download/ScaleFactory.dmg) |

Обычно скачивать отсюда не нужно: в рабочем кабинете есть страница
**«Установка»** — там те же кнопки и код вашей компании, который программа
спрашивает при первом запуске.

## Что это

Рабочий стол вместо браузера: на экране только разделы вашей роли, печать
идёт сразу на назначенный принтер без окна выбора, а внизу есть кнопка
«Позвать IT».

Программа обновляется сама.
